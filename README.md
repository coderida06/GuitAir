# GuitAir

A few years ago, I picked up the guitar. I learned to play quite a few songs, but only the tabs. Chords were a different story. My fingertips hated me, and I never had the time or patience to properly learn them. (I can play an E minor though.)

So I built **GuitAir**.

GuitAir is an OpenCV-based application that lets you play guitar chords using hand gestures. Instead of pressing strings on a guitar, you simply make different hand signs, and GuitAir plays the corresponding chord. It's made for people who want to sing along with a guitar, experiment with chord progressions, or just have fun.

> Ever wanted to sing with a guitar but have never touched one in your life? GuitAir lets you play guitar chords using simple hand gestures, so you can sing along. This version currently supports downstrums only.

## Current Features

*  Play guitar chords using hand gestures
*  Real-time hand tracking with OpenCV
*  Instant chord playback
*  Simple gesture-based controls
